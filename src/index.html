Customer groups

The processor saves each card on file under its own customer name, so one customer can appear several times (for example “Fig Deli”, “Fig Deli OTO” and “Fig Deli 4242”). Group those names and the whole dashboard treats them as one customer. Manual charges with no customer name can be added too, by their cardholder. Groups are kept in this browser and applied to every export you open.
